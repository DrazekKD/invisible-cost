# Invisible Cost — calculators

The page behind the [Invisible Cost](https://youtube.com/@invisiblecost) channel:
five calculators for the money that leaves without you seeing it go.

One self-contained `index.html`. No framework, no build step, no backend — every
figure is arithmetic in the browser and nothing a visitor types leaves their device.

The numbers here are the same ones the videos quote, and that is the point: a channel
whose whole promise is "here is the number" cannot have a calculator that disagrees
with it. Change one and check the other.

Served by GitHub Pages at **invisiblecost.net**.
